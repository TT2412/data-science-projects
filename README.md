四个项目按顺序推进，每个项目都是独立的仓库子目录。项目完成后能放进简历和 GitHub 主页。

## Python 零基础学习计划（前 4 周）

### 第 1-2 周：Python 基础
- 廖雪峰 Python 教程（免费，中文）：`https://liaoxuefeng.com/books/python/`，看 1-6 章（变量、字符串、list/dict、条件、循环、函数）
- 每天写 20 分钟：把练习题代码放进 `01-coursework/assignments/` 各自的文件夹

### 第 3-4 周：数据处理入门
- pandas 官方 10 minutes 教程（免费）：`https://pandas.pydata.org/docs/user_guide/10min.html`
- 用真实的城市数据（如深圳开放数据）做 3 次简单练习

### 每天同步进行
- LeetCode 刷题从第 3 周开始，先刷"数组"和"字符串"标签的高频题
- 保持 git 提交：**每天都至少 commit 一次**

## 面试要点提醒

每个项目都要能回答三个问题：
1. 这个项目解决了什么问题？
2. 用了什么方法/技术，为什么选它？
3. 遇到的最大困难是什么，怎么解决的？

写代码的人可以是我，**讲明白的人必须是你**。
